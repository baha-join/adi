# Веб-приложение столовой
Курсовой проект по дисциплине МДК.09.01.

## Стек технологий:
- Backend: Python, Django, Django REST Framework
- Frontend: Vue.js (Vite)
- База данных: SQLite

## Функционал:
- Меню с категориями и КБЖУ
- Корзина и оформление заказов
- Авторизация и регистрация
- Панель персонала для смены статусов
